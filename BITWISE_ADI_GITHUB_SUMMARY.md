## 🚀 Detailed Repository Portfolio

### 1. 🎯 [LocoMe](https://github.com/bitwise-adi/LocoMe)
*   **Tagline**: *A local-first, offline-ready habit tracker & task manager with read-only social accountability sharing.*
*   **Live Site**: [locome.bitwise-adi.dev](https://locome.bitwise-adi.dev)
*   **Tech Stack**: Next.js 15, TypeScript, Dexie.js (IndexedDB), Firebase Auth & Firestore, PWA, CSS.
*   **Key Features**:
    *   **Local-First Architecture**: Data stored instantly in browser IndexedDB via Dexie.js, ensuring offline usage and zero latency.
    *   **Cloud Sync**: Background sync with Firebase Firestore for cross-device persistence.
    *   **Consistency Heatmap**: 16-week GitHub-style activity grid visualizing habit streaks.

1. **Practical Utility Focus**: Projects originate from real-world student needs (automated college portal scraping, grade target calculators, habit trackers).
2. **Local-First & Client-Side Excellence**: Heavy preference for offline-first user experiences (`Dexie.js`, LocalStorage, client-side ZIP generators) to minimize latency and server dependency.
3. **Clean Code & Architectural Rigor**: Strong commitment to Clean Architecture, Domain-Driven Design (DDD), and GoF design patterns in Python and TypeScript.
4. **UI Craftsmanship**: Rejection of heavy cookie-cutter framework defaults in favor of custom Vanilla CSS systems, modern dark themes, glassmorphism, and dynamic visual micro-animations.
